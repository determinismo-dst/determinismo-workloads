1. DEVIATIONS

CG1. A jank loop (or fn-level `recur`) that never ends and has no side effect is undefined behavior in the emitted C++: an optimized build (-O1, -O2, -O3; JIT and AOT) may return from it or run off the function.
  ((fn [x] (loop [] (if x (recur) :done))) true)
    Clojure: never ends.  jank -O0: never ends.  jank -O1/-O2/-O3: undefined; LoopDeletion deletes the loop (its only exit value, :done, is loop-invariant), so the call returns :done.
  (loop [x 0] (if (< x 10) (recur (+ x 0.5)) x))          ; R24's third example
    Clojure: 10.0.  jank -O0: never ends (x is an int local, R24).  jank -O1+: undefined; likely SCCP proves x stays 0, the exit is dead, and LoopDeletion leaves `unreachable`: the wrapper fn runs into whatever code follows (crash or garbage).
  Path: cpp_processor.cpp gen(loop) 992-1022 (`while(true){` 1011, shadows `auto s(v)` 1007 / `object_ref s(v)` 1001, recur `continue;` 934); ir/processor.cpp gen_arity 261-317 (fn-level recur), gen(let) 522-591 (loop); the loop body's operations are inline (core/math.hpp always_inline `lt`/`add`/`sub`/`mul`/`div` on primitives, core/truthy.hpp `truthy`), so nothing in it is a side effect. clang: CGStmt.cpp 1009-1048 (mustprogress), LoopDeletion.cpp 105-115/436-505.

- Signed + - * overflow: defined (wraps) everywhere in emitted code (-fwrapv): R25 holds at every level, and 64-bit wrap is the documented behavior (round 1 D1, book).
- Shifts, quot/rem on objects, `long`/`double` (non-inline fns) run in libjank (math.cpp, compiled at the jank build's -O2 without -fwrapv): `bit-shift-left` with a count ≥ 64 or < 0 (math.cpp 562-568 `l_data << r_data`) and `quot` of a huge double (321-339 `static_cast<i64>`) are undefined there, independent of the user's -O (runtime agent's area; noted, not searched).
- Uninitialized reads: none; every local jank declares is value-initialized (`T v{ };`, cpp_processor.cpp 909-919; `auto` locals are initialized).
- Null dereference / wrong-type access: R47's `static_cast<jit_closure*>` of a non-closure (still UB at every level); otherwise emitted code reaches objects through checked runtime calls.
- Strict aliasing: emitted code does not reinterpret objects except R47; NaN-boxed values go through std::bit_cast (oref.hpp). No -fno-strict-aliasing is passed.
- `#line` (cpp_processor.cpp 1920-1932, only with --debug, the default) and cpp/raw's `#line` (processor.cpp 4195-4207): only diagnostics and __LINE__/__FILE__ change; lines start at 1 (read/source.hpp 21) and the file name is escaped (util/escape.cpp 148-197), so the directive is always well formed. No semantic effect.
- `GC_add_roots(&first, &last + 1)` (cpp_processor.cpp 2124-2134, 2160-2170; module target only): registers the lifted vars and constants as one address range, which assumes the namespace-scope globals are contiguous in declaration order. C++ gives no such guarantee; it holds for LLVM's in-order emission into one section (all are constant-initialized from `_jank_null`). If it failed, the GC could free a lifted constant (use after free). For an AOT executable the globals are in the main program's data segment, which bdwgc scans anyway; the range matters for object files loaded into the JIT. Assumption CGA5.

3. LEFT OUT, AND WHY
- LLVM's exact output for a UB program is not modeled: at -O1+ a UB path is reported as "undefined" with LangRef's license and the likely pass (SCCP/InstCombine poison, LoopDeletion); predicting the machine code would need the passes themselves.
- `^cpp/int` parameters have no Clojure counterpart; they are compared with ^long and their own class is set aside.
- Typed parameters of class/pointer types (Interop agent), BigDecimal constants (Boost agent), interop forms.
- The runtime library's own UB (math.cpp shifts, quot, real→i64 in to_integer) is noted, not searched (runtime agent).
- Round 2's depth-2 exhaustive control is bounded (partitions stopped at 20,000 timelines each): a complete walk would take hours at ~1 ms per timeline through the full pipeline.
- Native-world exhaustive search is complete at depth 1 with small pools; depth 2 (≈10^9 programs with these pools) is not feasible; depth 3 is sampled (2,000 seeds per mode + 20,000 residual seeds).
- Captured native locals in closures are covered only through `((fn [p] …) arg)` inside a `let` (closure contexts copy by value; nothing else differs).
- ir/print.cpp (debug printing only).

7. THEOREMS (no sorry, no native_decide, no axioms; decide/simp/omega)
Flags.lean:
- effectiveOpt_append_opt: the last `-O<n>` decides clang's level, whatever precedes it.
- jit_has_fwrapv / aot_has_fwrapv: for every build type and command line (and any JANK_EXTRA_FLAGS for AOT), `-fwrapv` is passed.
- jit_level: the JIT's clang level is the runtime level for every build type (Release's -O2 in JANK_JIT_FLAGS is overridden).
- aot_level: without JANK_EXTRA_FLAGS, AOT's clang level is the codegen level.
- run_levels: run/run-main/repl give the JIT the -O given; compile_jit_at_O0: compile/compile-module evaluate at -O0 whatever -O.
Theorems.lean:
- jit_loops_must_progress (with jit_std, jit_finite): for every build type and command line, every non-empty `while(true)` loop and every function jank JIT-compiles is mustprogress (std gnu++20, no -f[no-]finite-loops).
- decimal_text_type_int_iff: the C++ text of an integer is an `int` exactly on (-2^31, 2^31); int_min_literal_types: the analyzer says int, the text is long, for -2147483648 (CG8).
- halfStep_nonneg / halfStep_neg; r24_never_exits: for every n > 0 and every start c < n, jank's `(loop [x c] (if (< x n) (recur (+ x 0.5)) x))` stays below n forever (and never above max(c,0)); r24_clojure_exits: Clojure's reaches n after 2(n-c) steps. New for-every-input version of round 2's bounded R24 example.
Variadic.lean:
- only_variadic_agrees: for every required count 0..9 and 0..14 arguments, `[a1..ar & rest]` binds what Clojure binds (jit_variadic_function's switch and the packed 11th argument included).
- ambiguous_agrees: the same with a fixed arity of the same count (the ambiguous flag).
- eleven_to_twenty_fixed: for every 10 < p ≤ 20, jank rejects a p-parameter fn that Clojure compiles; ten_and_rest: `[a1..a10 & rest]` likewise (CG4).
Literals.lean:
- dup_pair, dup_set: run-time duplicate keys: Clojure throws, compiled jank keeps one entry (last value), the top level keeps both pairs (CG3).
- no_dup_agree: for every key list without a repeat (≤ 8 pairs) the three agree.
- quote_empty_meta_becomes_nil: eval of (quote v) turns v's {} metadata into nil; strip_changes_iff: for every key list, jank changes the metadata exactly when it is empty or holds :jank/source (CG6).
