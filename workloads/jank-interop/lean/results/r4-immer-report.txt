== 1. Deviations ==

C1. `with-meta` on an infinite `repeat` writes the meta into the repeat itself.
  (let [r (repeat 7)] (with-meta r {:a 1}) (meta r))            ; Clojure nil     jank {:a 1}
  (let [r (repeat 7)] (identical? r (with-meta r {:a 2})))       ; Clojure false   jank true
  Path: core.jank 3158-3161 `repeat` → obj/repeat.cpp `create` 34-37 (count infinite);
    repeat.cpp `with_meta` 124-130: `expect_object<repeat>(fresh_seq())`, then `ret->meta = meta`;
    `fresh_seq` 53-60 returns `this` when `count == infinite`. So the meta is set on the original object, which every
    holder of the seq shares (also `vary-meta`, and anything that attaches meta to a seq it was handed).
    A finite (repeat n x) gets a new object (fresh_seq 59). Clojure: Repeat.withMeta returns `new Repeat(meta, …)`.
  Replica: SeqObjects.jank `.withMeta` on `.rep none`: `h.set! r …` (same heap slot), class meta-mutated.
  Search: class meta-mutated in Q1–Q3 (559 of 119,019 at 3 steps); theorem c1_repeat_meta_written.
  Test: uC1-with-meta-leaves-an-infinite-repeat-alone. Status: new. Confidence: high.

  (meta (with-meta (range) {:a 1}))           ; the same: core.jank 2832 `(range)` is `(iterate inc 0)`
  Path: core.jank 2821-2825 → obj/iterator.cpp: the iterator object has no with_meta/get_meta/set_meta (not
    `metadatable`, behavior/metadatable.hpp 10-14; header iterator.hpp 16-18 behaviors seqable/sequence_like only);
    core/meta.cpp `with_meta` 37-58 → the non-metadatable arm throws `runtime_non_metadatable_value` whose message
    is built first with `typed_o->to_code_string()` (50-53) → iterator.cpp `to_code_string` → seq_to_code_string over
    the whole (infinite) sequence: the string builder grows until memory runs out. Clojure: Iterate extends ASeq,
    `withMeta` returns a new Iterate.
  Also: `(meta (iterate inc 0))` is nil in both (meta.cpp 13-35 returns nil for non-metadatable objects).
  Replica: `.iter` arm of `jank … .withMeta`: `.hang`. Search: class hang (794 at 3 steps); theorem c2_iterate_with_meta. Tests (hangs file): uC2-with-meta-on-an-iterate,
  uC2b-with-meta-on-an-infinite-range. Status: new. Confidence: high (that the error text is built eagerly from the
  value's code string: meta.cpp 50-53).

== 4. Still left out, and why ==
 - `take_mut` (and `take`) keeping a tree well formed: not proved, so the transient sequence theorem (get_conjs)
   covers `conj!` chains; `pop!` is covered for every well-formed tree (get_takeMut) but not chained after another
   `pop!`. Round 3 did not prove it for the persistent `take` either. The vector worlds V1/V1b (complete) and
   V2–V4 search the chains.
 - CHAMP laws other than get-after-add (get of another key after add, get after sub, count, iteration = entries,
   transient = persistent): not proved. Each needs `Equal` to be an equivalence agreeing with the hash on the keys
   present; jank's `=` is not (D12, R55), and stating the law with that premise means proving the hash-path
   uniqueness of every stored key through `do_add`/`do_sub`/`make_merged`/collision nodes and their `_mut` forms
   (round 3's get_doAdd alone is 110 lines for one branch family). The designed-hash censuses (M4/M5/S3, below)
   search exactly those paths with keys whose `=` is an equivalence.
 - M4 (persistent, 4 steps) and S3 (sets, 4 steps) complete: estimated 5.06·10^9 and 1.19·10^8 timelines
   (Knuth, 2,000 samples); at the measured 3,200–7,400 per second that is days and hours of a shared slot. Replaced
   by their complete 3-step worlds (M4-3, S3-3) plus round 3's covered prefixes.
 - Seq objects not modeled: native_array_sequence (C++ arrays only), persistent_string_sequence (round 2's R52–R56),
   ranges (round 2), lazy seqs beyond `with-meta` (round 2's R117–R119).

== 9. Library gaps (sdk/lean untouched) ==
 - Object identity for sequence objects: a heap (Array) of objects with jank and Clojure heaps side by side and live
   values as pairs of indices, so an in-place write (C1) shows on a value created earlier (SeqObjects.lean).

 - Proof engineering: Lean 4.36 cannot generate equation lemmas for `sliceMutInner` (a `let down … match k` inside a
   structural recursion); its two equations are stated and proved by `rfl` (definitional unfolding).

 - Resumable censuses and world-size estimates reused from round 3 (Kit.reportCensus, Search.estimate); long runs use a
   copy of the exe so a rebuild cannot touch a running binary.
