(5) ASSUMPTIONS
---------------
Standing (new):
- MODA4-1: A file's forms are evaluated one by one (eval_string), each at its own analysis; a
  top-level (ns ...) expands to a `do` analyzed whole (S71), which changes nothing here since
  its calls are qualified.
- MODA4-2: The spec for .jank is Clojure's for .clj (first class path element; .clj before .cljc).
- MODA4-3: Exceptions are compared as thrown or not; their types and messages are left aside.
- MODA4-4: Clojure 1.12 refer semantics for the spec; refer-conflict differences are set aside.
- MODA4-5: -main's references resolve in the main module when it is analyzed; *ns* matters only
  to run-time operations (eval, read-string ::k, resolve, require's aliases).
- MODA4-6: The AOT world's lifted vars are the module's references resolved in its namespace
  after its JIT load (eval_string analyzes the forms again after evaluating them).
- MODA4-7: The CLI spec is the --help text plus the book: an undocumented flag is an error, help
  exits 0.
- MODA4-8: recursive_directory_iterator order is the order files are given in the world.
Replaced: none (no earlier round modeled these parts).
