4. STILL LEFT OUT, AND WHY
======================================================================
- Frame layouts and register allocation of clang-compiled JIT code: they decide whether a stale
  word survives; not replicated (only every outcome allowed). So no GC freed read is predicted.
- Clojure's ReentrantReadWriteLock queueing (a new reader blocks behind a queued writer in non-fair
  mode): modeled as readers blocked only by a holding writer; every jank-only class found was
  re-read by hand (A12 involves no reader in Clojure).
- The multimethod method_cache read without the lock (a word-sized race; R3 noted it).
- Agents, refs/STM, with-local-vars, pmap, seque, future?, future-done?: unported ("TODO: port").
- macOS futures (RTA9 stands).

5. ASSUMPTIONS
======================================================================
Replaced:
- RTA8 (round 3: "conservative scanning finds no stale copy of a dead frame's pointers") → Gc4's
  conservative stack: live frames scanned (at -O0 every local's slot lives until the function
  returns), stale words of popped frames by decision. Consequence: S69, S70/RT8-RT9 freed reads
  withdrawn as predictions (possible, not certain).
- Round 3's "no callbacks under the JIT and multimethod recursive mutexes" → contradicted: hashing in
  add_method/prefer_method/remove_method realizes lazy dispatch values under the multimethod mutex,
  every call takes it (A12); cpp/raw initializers run under the JIT lock.
New:
- RTA4-1: a top-level form is evaluated by evaluate.cpp with the default eagerness (lazy); the
  test runner (`jank … run-main`) passes no --eager.
- RTA4-2: the default -O level (0) for JIT code; clang at -O0 keeps every local in its own slot.
- RTA4-3: stale-word survival is unknown (decision per word per collection).
- RTA4-4: Clojure's RRWL non-fair queueing not modeled (above).
- RTA4-5: realize's JIT steps (eval_string, create_function) take the interpreter lock briefly and
  run no user code (declarations only).
Still standing from round 3: RTA1-RTA7, RTA9-RTA11.
