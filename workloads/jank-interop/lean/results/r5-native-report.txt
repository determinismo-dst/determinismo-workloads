5. ASSUMPTIONS
======================================================================
- NatA5-1. jank release builds define NDEBUG (CMakeLists.txt 142-143, as earlier rounds' RC):
  llvm::cantFail on a failure is llvm_unreachable, undefined behavior (LLVM_UNREACHABLE_OPTIMIZE

- NatA5-2. Scripts and paths are ASCII; std::isalnum/std::isspace in the environment's LC_CTYPE agree
  with "C" on ASCII bytes.
- NatA5-3. dlopen accepts exactly loadable ELF shared objects; a text file, an archive or a refused
  ELF fails (the replica's Kind).
- NatA5-4. jank's install directories (its process dir and resource lib dir, which the AOT link
  also searches, aot/processor.cpp 187-195) hold no library of the user's name.
- NatA5-5. The AOT link's -L order is the user's dirs, then Clang's defaults (compiler args before
  linker args, aot/processor.cpp 249 and 362).
- NatA5-6. GNU ld 2.45 is the spec for a script and for -l; lld follows the same -l and script
  rules for these inputs.
- NatA5-7. LLJIT without the ORC runtime does not run an added object file's initializers (jank's
  own comment, processor_dynamic.cpp 672-673).
- Replaced: round 4's AOT model (Jank/R4/Modules/Aot.lean aotRun p false) let -main's throw reach
  jank_init_dynamic; it goes through jank_call2 (A1).
