Design
- Jank/R7/Gen/Core.lean: paths, draws, `choose`, Clojure text, the test file's header and wrappers.
  A draw is one operation and its operands; it is emitted on every path its model distinguishes:
    [literals] the call written directly (literal or native-producer arguments; the inline expands);
    [let] the arguments let-bound, then the call (analyze_let keeps each init's C++ type,
          analyze/processor.cpp 2370-2421; Clojure compiles primitive locals);
    [fn] object parameters, by one of three routes chosen per draw: a top-level defn- wrapper
          (fn:defn, as round 6's n-add), a local fn (fn:local), or apply (fn:apply);
    [mixed] (number models only) the call inlined in a local fn, one operand its object parameter,
          the other a literal: the native/object templates of core/math.hpp.
  Strings: the models predict every path alike (REPORT-6 3.3); the draws run on [literals], [let], [fn].
- Selection (`choose`, per stratum): the stratum's draws shuffled by `mkStdGen (Determinismo.mixSeed
  seed)`; first one draw failing on each path where the model has one (an explaining id not yet used
  first), then more failing draws (a new signature of ids across paths first, then the least used
  signature) up to half of the draws, then draws predicted to pass on every path. So each
  operation x path has failing and passing forms in roughly equal measure where the model has both.
- Each item: path, form, the one assertion (on Clojure's value), the model's Clojure value, the
  model's jank value, the verdict that assertion gets on jank's value, and the explaining id.
  Observations, chosen so jank's and Clojure's print forms do not decide a verdict:
    long, BigInt: (= "<digits>[N]" (pr-str E))  (kind shows: 1 vs 1N vs 1.0);
    double: (= <exact plain literal> E); ##NaN: (NaN? E); +-0.0: (= "0.0"/"-0.0" (str E));
    ratio: (= n/d E); BigDecimal: (let [v E] (and (decimal? v) (zero? (compare <lit>M v))));
    boolean: (true? E)/(false? E); compare's int, count, index: (= n E); nil: (nil? E);
    string: (= "<\u-escaped>" E); character: (= "<\u-escaped>" (str E)); Clojure throws: (thrown? E).
  The jank verdict evaluates exactly that assertion on jank's value: pr-str of round 3's JV.prStr,
  str of JV.str, `=` of round 3's jEqual (a real equals only a real), NaN? false on non-reals
  (math.cpp is_nan 641-656), `=` of strings by bytes, `str` of a character its bytes, and `thrown?`
  catching only object_ref (clojure/test.jank 493-504).
- Jank/R7/Gen/Num.lean, MinMax.lean, Native.lean, Str.lean: one per model (universes below);
  Jank/R7/Gen/Plan.lean: the strata, seeds, the emitted files, the bulk check; Run/R7/Gen.lean:
  `lake exe jank7-gen` (emit the test file, the TSV and .r7-scratch/gen/summary.txt) and
  `lake exe jank7-gen bulk N PATH` (up to N draws per stratum, every path, for the JVM).
