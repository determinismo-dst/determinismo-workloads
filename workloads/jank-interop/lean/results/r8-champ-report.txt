H8-1 (new). assoc/conj of a key already present reorders a hash map's or hash set's seq when that key
shares its full 32-bit hash with a key stored before it in their collision node.

    ; (Murmur3.hashLong, the same function)
    (let [m (hash-map (id 1) :a (id 7676047846) :a)]
      (= (keys m) (keys (assoc m (id 1) :b))))                         ; Clojure true, jank false
    (let [m (hash-map (id 1) :a (id 7676047846) :a)]
      (= (keys m) (keys (assoc m (id 1) :a))))                         ; Clojure true, jank false

      (= (seq s) (seq (conj s (id 1)))))                               ; Clojure true, jank false

                              (assoc! (id 1) :b))))
       (keys (-> (hash-map) (assoc (id 1) :a) (assoc (id 7676047846) :a) (assoc (id 1) :b))))

      so levels 7-12 index 0: round 3's IMA notes). Its order: the newest first. hash-map and
      hash-set of several values build through a transient (persistent_hash_map.cpp create_from_seq
      55-71, transient.set; persistent_hash_set.cpp create_from_seq 45-53, transient.insert), and the

      and call copy_collision_replace (champ.hpp 575-581; node.hpp 495-523), which writes the new
      value FIRST and the others after it. jank calls set/insert whatever the key's presence.
    - assoc! (transient_hash_map.cpp assoc_in_place 96-101 -> add_mut -> do_add_mut 645-) writes in
      place (`*fst = std::move(v)`, champ.hpp 652-655) only when the transient owns the collision

    - keys (core.jank 2316-2325) and seq walk champ_iterator (champ_iterator.hpp 97-98, 122-123:
      a collision node's array in order).
    - Clojure: HashCollisionNode.assoc replaces the value in place (PersistentHashMap.java 948-950,

  every hash, every equality, every owner token.
